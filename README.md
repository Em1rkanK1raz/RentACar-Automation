# 🚗 Rent A Car Otomasyon Sistemi

Bu proje, araç kiralama süreçlerini dijitalleştirmek, müşteri ve araç yönetimini kolaylaştırmak amacıyla geliştirilmiş bir masaüstü otomasyon yazılımıdır.

## ✨ Özellikler
- 🚘 **Araç Yönetimi:** Araç ekleme, silme, güncelleme ve müsaitlik durumu takibi
- 👤 **Müşteri Yönetimi:** Müşteri kayıtları ve kiralama geçmişi
- 📋 **Sözleşme & Kiralama:** Araç teslim alma/etme ve kiralama sözleşmesi oluşturma
- 📊 **Raporlama & Kasa:** Gelir-gider takibi ve aktif kiradaki araçlar

## 🛠️ Kullanılan Teknolojiler
- **Programlama Dili:** C# (.NET)
- **Arayüz:** Windows Forms
- **Veritabanı:** Microsoft SQL Server (MSSQL)

## 🚀 Kurulum
1. Bu projeyi bilgisayarınıza klonlayın veya zip olarak indirin.
2. `Rent A Car.bak` dosyasını SQL Server Management Studio (SSMS) üzerinden restore edin.
3. `RentACar otomasyonu.sln` dosyasını Visual Studio ile açıp `F5` ile projeyi çalıştırın.
